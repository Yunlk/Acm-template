const int MAX_M = 200005;

## 高精度整数运算

对应函数：

```cpp
string add(string a, string b);
string mul(string a, string b);
```

两个函数都只支持由字符 `'0'` 到 `'9'` 组成的非负整数，不处理符号、小数点或非法字符。结果会去除多余前导零，零返回 `"0"`。

### 数位表示

若十进制整数为

$$
A=\sum_{i=0}^{n-1} A_i10^i,
$$

其中 $A_i\in[0,9]$，则代码把字符串反转存入数组，使个位对应 $A_0$。这样从低位到高位扫描时，进位总是流向下一个下标。

### 高精度加法

对第 $i$ 位，设来自前一位的进位为 $c_i$，则

$$
s_i=A_i+B_i+c_i,
$$

$$
R_i=s_i\bmod 10,
\qquad
c_{i+1}=\lfloor\frac{s_i}{10}\rfloor.
$$

代码中的 `out[i]` 同时暂存本位和与前一位进位：

```cpp
out[i + 1] += out[i] / 10;
out[i] %= 10;
```

每一位只处理常数次，所以时间复杂度为 $O(n+m)$，结果数组长度最多为 $\max(n,m)+1$。

示例：

```cpp
add("999", "1");      // "1000"
add("00012", "003"); // "15"
```

### 高精度乘法

由分配律：

$$
AB=
(\sum_i A_i10^i)
(\sum_j B_j10^j)
=\sum_i\sum_j A_iB_j10^{i+j}.
$$

因此，进位前第 $k$ 位的系数为卷积：

$$
C_k=\sum_{i+j=k}A_iB_j.
$$

代码先执行

```cpp
C[i + j] += A[i] * B[j];
```

再从低位向高位统一进位：

$$
C_{i+1}=C_{i+1}+\lfloor\frac{C_i}{10}\rfloor,
\qquad
C_i=C_i\bmod10.
$$

共有 $nm$ 对数位相乘，所以时间复杂度为 $O(nm)$，空间复杂度为 $O(n+m)$。

```cpp
mul("123", "456"); // "56088"
mul("0", "999");   // "0"
```

## 快速幂

```cpp
ll qpow(ll a, ll b, ll mod);
```

计算

$$
a^b\bmod m.
$$

### 二进制分解

非负整数 $b$ 可以唯一写成

$$
b=\sum_{i=0}^{k}b_i2^i,
\qquad b_i\in\{0,1\}.
$$

于是

$$
a^b=
a^{\sum b_i2^i}
=\prod_{i:b_i=1}a^{2^i}.
$$

每轮将底数平方，相当于依次得到

$$
a,a^2,a^4,a^8,\ldots
$$

当指数当前最低位为 `1` 时，把对应幂乘入答案。

### 循环不变量

设初始目标为 $a_0^{b_0}$，循环中的变量为 `res`、`a`、`b`，始终保持

$$
res\cdot a^b\equiv a_0^{b_0}\pmod m.
$$

- 若 $b$ 为奇数，先令 `res = res * a`，再去掉这一位；
- 令 `a = a * a`、`b = b / 2` 后，剩余部分满足
  $(a^2)^{\lfloor b/2\rfloor}=a^{b-1}$ 或 $a^b$；
- 当 $b=0$ 时，不变量给出 `res` 就是答案。

指数每轮减半，因此时间复杂度为 $O(\log b)$。

```cpp
qpow(2, 10, MOD1); // 1024
qpow(3, 0, MOD1);  // 1
```

当前实现要求 `b >= 0`、`mod > 0`。负指数在右移后不保证收敛到 `0`，可能导致循环无法结束；负底数也不会被规范化到 `[0,mod)`。如果 `a*a` 或 `res*a` 超过 `long long` 范围，会在取模前溢出；大模数场景需要改用 `__int128` 或安全乘法。

## 最大公约数与最小公倍数

```cpp
ll gcd(ll a, ll b);
ll lcm(ll a, ll b);
```

### 欧几里得算法推导

由带余除法，存在整数 $q,r$ 使

$$
a=qb+r,
\qquad 0\le r<b.
$$

如果 $d$ 同时整除 $a,b$，则

$$
d\mid(a-qb)=r.
$$

反过来，如果 $d$ 同时整除 $b,r$，则

$$
d\mid(qb+r)=a.
$$

所以 $(a,b)$ 与 $(b,r)$ 的公因数集合完全相同：

$$
\gcd(a,b)=\gcd(b,a\bmod b).
$$

余数不断减小，直到第二个参数为 $0$，此时

$$
\gcd(a,0)=a.
$$

### 最小公倍数推导

对正整数 $a,b$，按质因数分解比较每个质因数的指数，可得

$$
\gcd(a,b)\cdot lcm(a,b)=ab.
$$

因此

$$
lcm(a,b)=\frac{a}{\gcd(a,b)}\cdot b.
$$

代码先除后乘，比直接计算 `a*b/gcd(a,b)` 更不容易溢出，但最后的乘法仍可能溢出。

```cpp
gcd(12, 18); // 6
lcm(12, 18); // 36
```

建议只传入非负整数；`lcm(0, 0)` 会除以零。

## 组合数学

### 模逆元

```cpp
ll modinv(ll a, ll mod);
```

模逆元 $a^{-1}$ 满足

$$
aa^{-1}\equiv1\pmod p.
$$

当 $p$ 是质数且 $p\nmid a$ 时，费马小定理给出

$$
a^{p-1}\equiv1\pmod p.
$$

两边乘以 $a^{-1}$：

$$
a^{p-2}\equiv a^{-1}\pmod p.
$$

所以代码调用

```cpp
qpow(a, mod - 2, mod);
```

复杂度为 $O(\log p)$。如果模数不是质数，或者 $a\equiv0\pmod p$，当前函数不保证返回有效逆元。

### 阶乘与逆阶乘预处理

```cpp
ll fac[MAX_M], invfac[MAX_M];
void pre_fac(ll mod);
```

阶乘定义为

$$
n!=\prod_{i=1}^{n}i,
\qquad 0!=1.
$$

正向递推：

$$
fac[i]
=fac[i-1]\cdot i\pmod p.
$$

代码先用一次快速幂求最大下标阶乘的逆元：

$$
invfac[M-1]
=((M-1)!)^{-1}\pmod p,
$$

其中 `M = MAX_M`。又因为

$$
(i+1)!=(i+1)i!,
$$

取逆后有

$$
(i!)^{-1}=((i+1)!)^{-1}(i+1).
$$

因此可以倒序在线性时间内得到全部逆阶乘：

$$
invfac[i]
=invfac[i+1](i+1)\pmod p.
$$

当前实现每次固定预处理到 `MAX_M-1`。必须满足模数 $p$ 为质数且

$$
p>M-1,
$$

否则最大阶乘可能包含因子 $p$，变为 $0\pmod p$，从而不存在逆元。

### 组合数

```cpp
ll C(ll n, ll r, ll mod);
```

从 $n$ 个不同元素中无序选出 $r$ 个：

$$
\binom nr=\frac{n!}{r!(n-r)!}.
$$

在模质数下，除法通过乘逆元完成：

$$
\binom nr\bmod p
=n!\,(r!)^{-1}\,((n-r)!)^{-1}\bmod p.
$$

预处理后单次查询为 $O(1)$。代码在 `r < 0` 或 `r > n` 时返回 `0`。

### 排列数

```cpp
ll A(ll n, ll r, ll mod);
```

从 $n$ 个不同元素中有序选出 $r$ 个：

$$
A_n^r=n(n-1)\cdots(n-r+1)=\frac{n!}{(n-r)!}.
$$

所以

$$
A_n^r\bmod p
=n!\,((n-r)!)^{-1}\bmod p.
$$

### 卡特兰数

```cpp
ll catalan(ll n, ll mod);
```

第 $n$ 个卡特兰数为

$$
Cat_n
=\frac{1}{n+1}\binom{2n}{n}.
$$

一种推导来自合法括号序列。把左括号视为向上一步，右括号视为向下一步。长度 $2n$ 且各有 $n$ 个左右括号的序列共有

$$
\binom{2n}{n}
$$

个。合法序列要求任意前缀中左括号数不少于右括号数。

对第一次落到高度 $-1$ 的非法路径，将起点到该位置的上下步互换。反射后得到一条含 $n-1$ 个上步、$n+1$ 个下步的路径，因此非法路径数为

$$
\binom{2n}{n+1}.
$$

合法路径数为

$$
Cat_n
=\binom{2n}{n}-\binom{2n}{n+1}.
$$

$$
Cat_n=\binom{2n}{n}(1-\frac{n}{n+1}).
$$

$$
Cat_n=\frac{1}{n+1}\binom{2n}{n}.
$$

代码用 `modinv(n + 1, mod)` 执行除法，因此单次 `catalan` 的实际复杂度是 $O(\log p)$，不是 $O(1)$。另外必须有 `2*n < MAX_M`。

典型应用包括合法括号序列、二叉搜索树形态、栈的合法出栈序列和不越过对角线的格路径。

```cpp
pre_fac(MOD1);
C(5, 2, MOD1);      // 10
A(5, 2, MOD1);      // 20
catalan(3, MOD1);   // 5
```

## 埃拉托斯特尼筛法

```cpp
vector<ll> get_primes(ll n);
void init_sieve(ll n);
bool is_prime(ll n);
```

- `get_primes(n)` 返回闭区间 $[2,n]$ 内的质数列表，但内部判质数组不会保留。
- `init_sieve(n)` 把筛选结果保存到全局 `_isp`。
- `is_prime(x)` 查询 `_isp[x]`；未初始化或越界时返回 `false`。

### 为什么从 $i^2$ 开始标记

筛到质数 $i$ 时，它的小于 $i^2$ 的倍数可以写成

$$
ki,\qquad 2\le k<i.
$$

其中因子 $k<i$，所以这个数已经在处理 $k$ 的某个质因子时被标记。因而只需从

$$
i^2,i^2+i,i^2+2i,\ldots
$$

开始。

当 $i^2>n$ 后，不再需要标记新合数，但仍要继续扫描数组，把尚未标记的数加入质数列表。

### 复杂度来源

每个质数 $p$ 大约标记 $n/p$ 个倍数，总工作量近似

$$
n\sum_{p\le n}\frac1p.
$$

质数倒数和渐近为 $\log\log n+O(1)$，所以埃筛时间复杂度为

$$
O(n\log\log n),
$$

空间复杂度为 $O(n)$。

```cpp
init_sieve(30);
is_prime(29);     // true
is_prime(30);     // false
get_primes(10);   // {2, 3, 5, 7}
```

当前两个筛函数都直接写入下标 `0` 和 `1`，因此要求 `n >= 1`。

## KMP 字符串匹配

```cpp
vector<int> kmp(string& s, string& p);
```

返回模式串 `p` 在文本串 `s` 中所有匹配的起始下标，结果使用 `0` 下标，并支持重叠匹配。

### 最长相等真前后缀

对模式前缀 $p[0\ldots i]$，令 `pi[i]` 表示满足下面条件的最大长度 `L`：

$$
0\le L<i+1,
\qquad
p[0\ldots L-1]=p[i-L+1\ldots i].
$$

`pi[i]` 是最长的、既是前缀又是后缀的真子串长度。当前代码没有直接存长度，而是存最后一个下标：

$$
nxt[i]=\pi[i]-1.
$$

因此 `j` 表示当前已经匹配到模式串下标 `j`，匹配长度为 $j+1$。

### 失配转移为什么正确

若已经匹配 $p[0\ldots j]$，但下一个字符失配，则已匹配文本后缀中，仍可能作为新匹配开头的最长部分，正是 $p[0\ldots j]$ 的最长相等真前后缀。

所以代码执行：

```cpp
j = nxt[j];
```

若仍失配，就继续寻找更短的相等真前后缀。文本下标 `i` 不需要回退，因为这些候选状态都表示“以当前已扫描位置结尾”的后缀。

### 线性复杂度

虽然存在 `while` 回退，但 `j` 每次回退都会严格减小；增长只能随文本或模式下标前进发生。增长和下降的总次数都是线性的，因此构造失败函数和匹配分别为 $O(m)$、$O(n)$。

匹配完成后执行

```cpp
j = nxt[j];
```

保留最长可复用后缀，所以能够找到重叠匹配：

```cpp
string s = "aaa", p = "aa";
kmp(s, p); // {0, 1}
```

当前实现要求模式串非空；`p.empty()` 会访问越界。文本串可以为空。

## 一维与二维前缀和

### 一维前缀和

```cpp
vector<ll> prefix_sum(vector<ll>& a);
```

定义

$$
pre[0]=0,
\qquad
pre[i+1]=\sum_{k=0}^{i}a[k].
$$

递推式为

$$
pre[i+1]
=pre[i]+a[i].
$$

闭区间 $[l,r]$ 的和为

$$
\sum_{k=l}^{r}a[k]
=pre[r+1]-pre[l].
$$

预处理 $O(n)$，每次区间查询 $O(1)$。

```cpp
vector<ll> a = {1, 2, 3, 4, 5};
auto pre = prefix_sum(a);
ll sum = pre[5] - pre[1]; // a[1..4] = 14
```

空数组可以安全返回 `{0}`，但累加过程可能发生 `long long` 溢出。

### 二维前缀和

```cpp
vector<vector<ll>> prefix_sum_2d(vector<vector<ll>>& a);
```

令 `pre[i][j]` 表示原矩阵左上角半开区域

$$
[0,i)\times[0,j)
$$

的元素和。加入原矩阵元素 $a[i-1][j-1]$ 时，上方矩形与左侧矩形的交集被计算了两次，因此需要容斥：

$$
pre[i][j]
=pre[i-1][j]
+pre[i][j-1]
-pre[i-1][j-1]
+a[i-1][j-1].
$$

对原矩阵中的闭矩形

$$
[x_1,x_2]\times[y_1,y_2],
$$

其元素和为

$$
S=pre[x_2+1][y_2+1]-pre[x_1][y_2+1]-pre[x_2+1][y_1]+pre[x_1][y_1].
$$

前两次减法分别去掉上方和左方区域，它们的交集被减了两次，最后加回一次。

构建复杂度为 $O(nm)$，单次矩形查询为 $O(1)$。当前实现要求外层数组非空并且所有行长度相同。

## 动态规划

### 最大子段和

```cpp
ll max_subarray(vector<ll>& a);
```

设 `f_i` 表示以位置 `i` 结尾的非空连续子段最大和。

任何以 $i$ 结尾的最优子段只有两种来源：

1. 从 $a_i$ 重新开始；
2. 把 $a_i$ 接到以 $i-1$ 结尾的最优子段后。

所以

$$
f_i=\max(a_i,f_{i-1}+a_i).
$$

全局答案为

$$
\max(f_0,f_1,\ldots,f_{n-1}).
$$

代码中的 `cur` 保存 $f_i$，`ans` 保存已经扫描部分的最大值，因此只需要 $O(1)$ 额外空间。

```cpp
vector<ll> a = {-2, 1, -3, 4, -1, 2, 1, -5, 4};
max_subarray(a); // 6，对应 [4, -1, 2, 1]
```

`ans` 初始化为 `a[0]`，所以全负数组也能正确返回最大的单个元素；代价是数组不能为空。

### 01 背包

```cpp
ll knapsack_01(vector<ll>& w, vector<ll>& v, int n, int W);
```

每件物品最多选择一次。定义 `f[i][j]` 表示只考虑前 `i` 件物品、容量不超过 `j` 时的最大价值。

第 $i$ 件物品重量为 $w_i$、价值为 $v_i$。不选或选一次：

$$
f_{i,j}=f_{i-1,j}\quad(j<w_i).
$$

$$
f_{i,j}=\max(f_{i-1,j},f_{i-1,j-w_i}+v_i)\quad(j\ge w_i).
$$

压缩到一维后，`dp[j-w[i]]` 必须仍代表上一层 $f_{i-1,*}$。因此容量需要倒序：

```cpp
for (int j = W; j >= w[i]; --j)
    dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
```

若改成正序，较小容量刚更新的第 $i$ 件物品会被再次使用，从而错误地变成完全背包。

### 完全背包

```cpp
ll knapsack_full(vector<ll>& w, vector<ll>& v, int n, int W);
```

每件物品可以选择任意次。其状态转移可写为

$$
f_{i,j}=f_{i-1,j}\quad(j<w_i).
$$

$$
f_{i,j}=\max(f_{i-1,j},f_{i,j-w_i}+v_i)\quad(j\ge w_i).
$$

注意第二项仍在第 $i$ 层，因为选择一次第 $i$ 件物品后还可以继续选择它。压缩后容量正序扫描，刚更新的 `dp[j-w[i]]` 才能继续参与转移：

```cpp
for (int j = w[i]; j <= W; ++j)
    dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
```

### 两种背包的区别

| 项目 | 01 背包 | 完全背包 |
|---|---|---|
| 每件物品使用次数 | 至多一次 | 任意次 |
| 二维转移来源 | 上一层 `i-1` | 当前层 `i` |
| 一维容量顺序 | 从大到小 | 从小到大 |
| 时间复杂度 | $O(nW)$ | $O(nW)$ |
| 空间复杂度 | $O(W)$ | $O(W)$ |

`dp` 初始化为 `0`，所以两个函数求的是“总重量不超过 `W` 的最大价值”，允许不选物品，不是“恰好装满”。代码要求重量为正，否则完全背包的数学模型可能无界，而实现不会正确表达这种情况。

## 一维与二维差分

差分可以视为前缀和的逆运算，适合处理多次区间加法，最后统一还原。

### 一维差分

```cpp
void diff_add(vector<ll>& d, int l, int r, ll v);
```

对原数组 $a$，定义

$$
d_0=a_0,
\qquad
d_i=a_i-a_{i-1}\quad(i\ge1).
$$

则

$$
a_i=\sum_{k=0}^{i}d_k.
$$

若把闭区间 $[l,r]$ 内每个元素都增加 $v$：

- $a_l-a_{l-1}$ 增加 $v$，所以 `d_l += v`；
- 区间内部相邻元素同时增加 $v$，差值不变；
- $a_{r+1}-a_r$ 减少 $v$，所以 `d_{r+1} -= v`。

因此一次区间修改只需：

$$
d_l=d_l+v,
\qquad
d_{r+1}=d_{r+1}-v.
$$

调用 `prefix_sum(d)` 后，原位置 $i$ 的还原值位于返回数组的下标 `i+1`：

```cpp
vector<ll> d(n + 1, 0);
diff_add(d, 1, 3, 5);
auto recovered = prefix_sum(d);
// recovered[2], recovered[3], recovered[4] 分别对应位置 1, 2, 3
```

必须为 `r+1` 预留空间。

### 二维差分

```cpp
void diff2d_add(
    vector<vector<ll>>& d,
    int x1, int y1, int x2, int y2, ll v
);
void diff2d_recover(vector<vector<ll>>& d, int n, int m);
```

二维差分可定义为原矩阵的离散二阶差：

$$
d_{i,j}
=a_{i,j}-a_{i-1,j}-a_{i,j-1}+a_{i-1,j-1}.
$$

反过来，二维前缀和可以还原原矩阵：

$$
a_{i,j}
=d_{i,j}+a_{i-1,j}+a_{i,j-1}-a_{i-1,j-1}.
$$

给闭矩形 $[x_1,x_2]\times[y_1,y_2]$ 全部增加 $v$ 时，先让影响从左上角开始：

$$
d_{x_1,y_1}=d_{x_1,y_1}+v.
$$

再在矩形下边界和右边界之后终止影响：

$$
d_{x_2+1,y_1}=d_{x_2+1,y_1}-v,
\qquad
d_{x_1,y_2+1}=d_{x_1,y_2+1}-v.
$$

右下角外侧同时被减了两次，需要加回：

$$
d_{x_2+1,y_2+1}=d_{x_2+1,y_2+1}+v.
$$

这就是代码的四角修改。每次矩形修改为 $O(1)$，全部修改完成后调用 `diff2d_recover`，用 $O(nm)$ 还原。

当前还原函数按 `1..n`、`1..m` 扫描。若有效坐标也采用该范围，建议分配至少 `(n+2) * (m+2)`，以容纳 `x2+1` 和 `y2+1` 哨兵。

## DFS 组合枚举

```cpp
void dfs_pick(
    int pos, int n, int k,
    int cnt, int sum,
    int a[], int& ans
);
```

在位置 `pos` 有两个分支：

1. 选择 `a[pos]`，令 `cnt+1`、`sum+a[pos]`；
2. 不选择，保持 `cnt` 和 `sum`。

每个大小为 $k$ 的下标集合都对应唯一的一条选择路径，因此有效叶子数量为

$$
\binom nk.
$$

但当前代码没有“剩余元素不足”的剪枝，并且还会访问不完整选择对应的递归状态，最坏时间复杂度仍按 $O(2^n)$ 估计，递归深度为 $O(n)$。

调用形式：

```cpp
int ans = 0;
dfs_pick(0, n, k, 0, 0, a, ans);
```

当前 `cnt == k` 分支中的检查与 `ans++` 都被注释掉，所以函数不会修改答案。它只是一个需要按题目补全的搜索骨架。

常见剪枝条件是 `cnt > k`，或者 `cnt + (n - pos) < k`。

## 八邻域计数

```cpp
ll neighbor_sum(ll n, ll m, ll target, int grid[][MAX_M]);
ll neighbor_sum_undirected(ll n, ll m, ll target, int grid[][MAX_M]);
```

`neighbor_sum` 的实际计算式是

```math
S = \sum_{i=0}^{n-1}\sum_{j=0}^{m-1}
    \sum_{(u,v)\in D} b_{i,j,u,v}
```

其中，$b_{i,j,u,v}=1$ 当且仅当 $0\le i+u<n$、$0\le j+v<m$ 且
$grid_{i+u,j+v}=target$；否则 $b_{i,j,u,v}=0$。

这里的 $b_{i,j,u,v}$ 就是对应条件的指示函数：条件成立时为 $1$，否则为 $0$。

它统计的是“从每个格子出发，指向值为 `target` 的相邻格子的有向邻接次数”。它没有要求出发格子的值也是 `target`。

### 为什么当前除以 2 一般不成立

考虑一条无向相邻边 $\{x,y\}$。它对 `neighbor_sum` 的贡献为

$$
[grid_x=target]
+[grid_y=target].
$$

所以：

| 两端情况 | 对有向计数的贡献 |
|---|---:|
| 都不是 `target` | 0 |
| 恰有一端是 `target` | 1 |
| 两端都是 `target` | 2 |

直接除以 $2$ 会把“恰有一端是目标值”的边算成半条，多个这样的贡献经过整数除法后也没有明确的图论含义。因此当前 `neighbor_sum_undirected` 只在额外条件保证所有贡献成对出现时才有意义，不能作为一般的无向目标邻接边计数。

若要统计“两端都等于 `target` 的无向相邻边”，需要先同时检查当前格子与邻居，再将有向总数除以 $2$；或者只枚举八方向中的四个方向，避免重复。

函数形参 `int grid[][MAX_M]` 还要求传入原生二维数组的物理第二维恰好为 `MAX_M`，不能直接传 `vector<vector<int>>`。

## 计时器

```cpp
void tick();
ll tock();
```

- `tick()` 记录当前时刻；
- `tock()` 返回从最近一次 `tick()` 到当前经过的整毫秒数。

```cpp
tick();
// code to measure
cerr << tock() << " ms\n";
```

`duration_cast<chrono::milliseconds>` 会舍弃不足一毫秒的部分。当前代码使用 `high_resolution_clock`，标准不保证它一定是单调时钟；如果要严谨测量耗时，通常应使用 `steady_clock`，并重复运行后取统计量。该计时器适合本地粗略比较，不应参与提交答案的标准输出。

## 前置条件与已知限制

下表描述的是当前 `codebook.cpp`，不是建议中的理想接口。

| 位置 | 当前限制或风险 | 违反后的可能结果 |
|---|---|---|
| `add` / `mul` | 只接受非负十进制数字串 | 非数字字符会产生无意义数位；不支持负数 |
| `mul` | 卷积数组元素类型为 `int` | 极长字符串可能让单个系数溢出 |
| `qpow` | `b >= 0`、`mod > 0` | 负指数可能无法结束循环；`mod == 0` 导致除零 |
| `qpow` | 底数最好先规范化到 `[0,mod)` | 负底数可能产生负的取模结果 |
| `qpow` | 乘法必须在 `long long` 内 | 大模数下取模前溢出 |
| `gcd` / `lcm` | 建议非负输入 | 负数符号不统一 |
| `lcm` | 输入不能同时为 `0` | `0 / gcd(0,0)` 导致除零 |
| `pre_fac` | 模数为质数且大于 `MAX_M-1` | 最大阶乘可能为 0，逆阶乘全部失效 |
| `C` / `A` | 先以同一模数调用 `pre_fac`，且下标小于 `MAX_M` | 使用未初始化值或数组越界 |
| `catalan` | `2*n < MAX_M` 且 `n+1` 可逆 | 数组越界或模除法无效 |
| `get_primes` / `init_sieve` | `n >= 1` | 对 `_isp[1]` 越界 |
| `is_prime` | 查询范围不能超过最近筛选上界 | 越界查询固定返回 `false`，不执行实时判定 |
| `kmp` | `p` 必须非空 | 访问 `p[0]` 越界 |
| `prefix_sum_2d` | 外层非空、矩阵规则 | `a[0]` 或较短行越界 |
| `max_subarray` | 数组非空 | `a[0]` 越界 |
| 两种背包 | `w.size(),v.size() >= n`，`W >= 0`，重量为正 | 数组越界、循环异常或模型无界 |
| `diff_add` | `0 <= l <= r` 且 `r+1 < d.size()` | 数组越界 |
| `diff2d_add` | 所有四角下标已分配 | 数组越界 |
| `dfs_pick` | 需要自行恢复检查逻辑 | 当前调用永远不会增加 `ans` |
| `neighbor_sum_undirected` | 除以 2 需要贡献成对 | 一般输入下结果没有预期的无向计数含义 |
| 所有 `ll` 累加 | 中间结果不超过 64 位范围 | 有符号整数溢出，结果不可靠 |

此外，多个函数使用非常量引用，例如 `kmp(string&, string&)` 和 `prefix_sum(vector<ll>&)`，但实际上不会修改参数；调用字面量或 `const` 对象时需要先存入变量。
